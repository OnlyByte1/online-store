# Интернет-магазин на React.js

https://github.com/user-attachments/assets/28937f75-06f5-4f17-ab1e-a1c32c4a9fab

Простой и функциональный интернет-магазин с современным интерфейсом, разработанный на базе библиотеки **React.js**. Проект демонстрирует навыки управления состоянием приложения, интеграции компонентов и реализации базового e-commerce функционала.

## ✨ Особенности

* **Каталог товаров:** Интуитивно понятный просмотр доступного ассортимента.
* **Корзина покупок:** Возможность добавлять, удалять товары и управлять их количеством.
* **Интерактивный UI:** Быстрый отклик интерфейса без перезагрузки страниц.
* **Адаптивный дизайн:** Корректное отображение на мобильных устройствах и десктопах.

## 🛠 Стек технологий

* **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
* **Сборщик:** Vite / Create React App

## 🚀 Запуск проекта

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd online-store
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки
```bash
npm run dev
# или npm start (в зависимости от ваших скриптов в package.json)
```

## 📂 Структура проекта
* `src/components/` — Переиспользуемые UI-компоненты (карточки товаров, корзина, хедер).
* `src/context/` или `src/store/` — Логика управления состоянием (если используется Context API / Redux).
* `src/assets/` — Статические файлы, стили и изображения.

## 🎓 Статус проекта
Это **учебный проект**, созданный в рамках изучения библиотеки React.js. 
Цель проекта — отработка навыков управления состоянием (state management), работы с компонентами, хуками и создания интерактивных интерфейсов для e-commerce.
